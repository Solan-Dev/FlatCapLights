# HatLights Documentation

This folder contains working docs for the Plasma 2350 W hat LED project.

## Start Here

- `quick-workflow.md` - the day-to-day development and upload loop.
- `board-reference-plasma-2350w.md` - board details, firmware notes, and hardware links.
- `http-api-reference.md` - HTTP control endpoint notes.

## Recommended Working Pattern

1. Keep board code mirrored in `device/`.
2. Edit in VS Code.
3. Use MicroPico to upload files and open REPL.
4. Test on the board immediately.
5. Keep the board files small and focused.
